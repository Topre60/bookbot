      How Inkling works

      Dialogue, fast

      1. Add characters in the Cast panel. Each gets a one-letter button and a shortcut: Alt+1, Alt+2…
      2. Press Alt+1 (or click J). Type the line and press Enter:
        “Did you bring it?” asks Jun.
      3. Turn on ⇄ Back and forth and Enter hands the next line to the other character. Enter on an empty quote stops.
      4. Select a line you already wrote and press a character’s key to quote and tag it.

      Screenplay

      1. Tab cycles elements; Ctrl/⌘+1–6 jumps to one. Enter picks the next element for you.
      2. Lines starting with INT. or EXT. become scene headings. Export PDF uses standard screenplay margins on US Letter.

      Everything else

      • Ctrl/⌘+K command palette: jump to any piece or run any command.
      • Ctrl/⌘+Shift+F focus mode. Ctrl/⌘+Shift+T typewriter scrolling.
      • Each piece is a .inkling file in your library folder, saved as you type.
      • Select lines and press Ctrl/⌘+Shift+M to move them into Side notes (bottom right), or Ctrl/⌘+Shift+J to copy. Insert puts a note back at the cursor.

        Word goal

        A target to reach, or a limit to stay under, like a 100-word drabble or a 1,000-word flash contest. Text past a limit turns red.
